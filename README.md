# AI Legal Assistant

AI Legal Assistant — это интеллектуальный юридический помощник, разработанный для анализа, создания и управления юридическими документами. Проект использует современные технологии искусственного интеллекта для автоматизации рутинных юридических задач.

## Структура проекта

Проект разделен на две основные части:
- **frontend** — пользовательский интерфейс на базе React и Vite.
- **backend** — серверная часть на базе FastAPI и Python.

## Запуск проекта

Убедитесь, что у вас установлены Node.js (для frontend) и Python (для backend).

### Backend
Перейдите в директорию `backend`, установите зависимости из `requirements.txt` и запустите сервер FastAPI.

### Frontend
В корневой директории установите зависимости (`npm install`) и запустите режим разработки (`npm run dev`).
